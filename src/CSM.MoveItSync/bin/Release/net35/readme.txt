CSM.MoveItSync - Synchronization Bridge for Move It
===================================================

This mod is a synchronization bridge for Cities: Skylines Multiplayer (CSM).

GitHub (this mod): https://github.com/RuisSoftware/CSM.MoveItSync/releases
Compatibility: Cities: Skylines 1 (v1.21.x) and CSM v2603.307.

Status: UNSTABLE ALPHA
- Basic object moving/rotation/scaling works.
- Road bending and node segments are currently NOT synchronized correctly.
- Use at your own risk! Undiscovered desync issues may occur.

Dependencies:
-------------
1. Move It (Original Mod)
   - Steam: https://steamcommunity.com/sharedfiles/filedetails/?id=1619685021
   - GitHub: https://github.com/Quboid/CS-MoveIt
   - NOTE: If Move It updates, this bridge might break. For best stability, use version 2.10.9 from their GitHub.

2. Cities: Skylines Multiplayer (CSM)
   - Steam: https://steamcommunity.com/sharedfiles/filedetails/?id=1558438291
   - GitHub: https://github.com/CitiesSkylinesMultiplayer/CSM

Only for use with Cities: Skylines 1. Created by the CSM Team.
